# TimeChime
Daily alarm clock system with e-Paper display.


## Software
* [Zephyr RTOS](https://docs.zephyrproject.org/latest/index.html)
* [Inter font](https://rsms.me/inter/)

## Hardware
* [Adafruit Feather m4 express](https://www.adafruit.com/product/3857)
* [Adafruit GPS Featherwing](https://www.adafruit.com/product/3133)
* [Adafruit Music Maker Featherwing](https://www.adafruit.com/product/3436)
* [Speakers x2](https://www.adafruit.com/product/1313)
* [Waveshare 4.2" e-Paper display](https://www.waveshare.com/4.2inch-e-paper-module.htm)
* [Buttons](https://www.adafruit.com/product/1009)
* SD Card
* Wire
* Micro-USB cable
